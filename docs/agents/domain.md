# Domain docs

This repository uses a single-context layout.

Before exploring an area:
- Read the root GLOSSARY.md if present.
- Read relevant decisions under docs/adr/.

If these files do not exist, proceed silently. Do not create placeholders.
The domain-modeling skill creates them when terms or decisions are resolved.

Use the glossary's terms consistently.
Explicitly flag proposals that contradict an existing ADR.
